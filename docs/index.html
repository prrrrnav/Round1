Practice investigating realistic integration failures inside a multi-file Node.js codebase. Trace requests through routes, middleware, controllers, services, and data access; inspect logs and API responses; fix the defect; then run the scenario tests.

View the codebase on GitHub Assessment README

Choose a scenario

  • Customer API integration: diagnose authentication, payload mapping, and invoice sync failures; reproduce requests in the integration browser and explain the resolution to a customer.
  • MongoDB webhook processing: investigate signature validation, duplicate deliveries, idempotency, and event persistence through repository and service layers.

The assessment workspace includes a VS Code-style file explorer and editor, multiple file tabs, documentation, request browser, console output, and scenario-specific tests.

Run the interactive assessment

GitHub Pages serves static content only. The interactive editor, code execution, API browser, and tests require the Node.js assessment server, so this Pages site provides the project and local startup instructions instead of showing a non-working editor.

git clone https://github.com/prrrrnav/Round1.git
cd Round1
npm install
npm start
# open http://localhost:3000
